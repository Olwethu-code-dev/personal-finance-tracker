# Personal Finance Tracker


The Personal Finance Tracker is a web-based application designed to help users manage their personal finances.

Users can create an account, log in, record income and expenses, create budgets, view financial reports and monitor their current balance.



- User registration and login
- Personalized user profiles
- Add and delete income
- Add and delete expenses
- Create budgets
- View financial reports
- Dashboard with financial totals
- User-specific financial data
- Logout functionality



- HTML5
- CSS3
- JavaScript
- localStorage
- Visual Studio Code
- Live Server
- Git and GitHub


1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the application using Live Server.
5. Register a new account and log in.
=

Register → Login → Dashboard → Income / Expenses / Budget / Reports / Profile → Logout



The purpose of this application is to provide users with a simple way to record and monitor their income, expenses and budgets in one place.

## Project Structure

- `index.html` – Login page
- `register.html` – User registration
- `dashboard.html` – Main dashboard
- `income.html` – Income management
- `expenses.html` – Expense management
- `budget.html` – Budget management
- `reports.html` – Financial reports
- `profile.html` – User profile
- `styles.css` – Application styling
- `script.js` – Application functionality
